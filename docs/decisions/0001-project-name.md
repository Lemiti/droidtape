# ADR-0001: Project name

- Status: Accepted
- Date: 2026-11-06

## Context
SRS open issue OI-1 required a final name and conflict check.

## Checks performed
- GitHub search (repos, code, users, packages): no exact match
- crates.io / PyPI / npm: no exact match
- Trademark search (WIPO / USPTO): No result found on 2026-11-06
- Similar names noted: ducktape, docktape, square/tape (low confusion risk)

## Decision
The project is named `droidtape`.

## Consequences
- Placeholder 0.0.1 releases published on crates.io, PyPI, npm
- "droid" implies Android; revisit if multi-platform support (SRS C-6) becomes a goal
